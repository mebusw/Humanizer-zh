# 角色卡 · 申导

**对象**：Jacky Shen（申导 / 申健），上海优普丰企业管理咨询有限公司（UPerform）创始人，首席敏捷教练，Scrum Alliance 认证 CST。

**语料基础**：11 份口语音料（课程现场录音转写、企业公开课实录）+ 1 篇公众号演讲实录，合计约 11.8 万中文字符。语料已随本角色归档在 `语料/` 下。

## 0. 这张卡怎么用

- **只描述表达方式**：句长、节奏、用词、标点、互动方式、修辞习惯。
- **不提供内容**：他的经历、案例、数字、客户名、观点立场一律不得移入目标文本。
- **两档语域差别很大**，编辑前先对号入座：

| 语域 | 典型场景 | 句子均长 | 破折号/千字 | 顿号/千字 | 第一人称"我"/千字 | "对吧"/千字 |
|---|---|---|---|---|---|---|
| **A. 现场口语** | 课程直播、公开课、企业内训互动 | 25–29 字 | 0 | 1.6 | 21.9 | 5.0 |
| **B. 演讲实录发布稿** | 会议演讲的公众号成稿（经编辑整理） | 42 字 | 4.6 | 14.7 | 9.6 | 0 |

**A 与 B 之间的差别不是"更正式一点"，而是两套体系**：B 稿的口语填充词几乎被清空（"对吧" 0 次、"然后" 0.18/千字、"所以" 0 次），顿号和破折号回归，段落被切成短块。**把 A 档的"对吧"塞进 B 稿，或把 B 稿的书面感塞回课堂口语，都是失真。**

- **第三档（纯书面长文 / 公众号技术文章）目前没有语料**。本卡不给这一档的基线；遇到这类任务，按输入文本自身的语域处理，不要硬套。

## 3. 节奏与韵律

### 3.1 A 档：短句砸，长句铺

典型序列：短句起 → 长句推演 → 短句收。

> "需求提了半天……少说三个月，三个月还得开发测试上线，上线以后你一按不是你想要的。完了，这一年就过去了，对吧？"

**同词紧邻重复**是主要强调手段（不用更响的形容词）：
- "就这么就这么快就这么快"
- "重复这个轮回，重复这个轮回"
- "判断不了判断不了"
- "一代一代一代人有一代人的机遇和挑战"
- "啪啦啪啦就做出来了"

**自打断与重启**："不过不过我们不是说要外发的"——允许自己改口，改口本身就是现场感。

**冗余叠加**："很多很多""特别特别""完完全全"——口语里不精确，转书面时要清掉。

**拖长音节**："啪啦啪啦""OKOKOK""拜拜拜拜"——只在收尾和情绪处出现。

### 3.2 B 档：短段落切块 + 破折号补充 + 顿号列举

- **短段落率反而比口语高（25% ≤15 字）**，但这些短块不是口语式的"砸"，而是书面式的"列要点"。
- **破折号承担"结论前的补充"**：
  > "虽然这个尝试不算成功，但方向是对的——由文生图、由图生成前端代码是未来趋势。"
  > "很多人抱怨AI'胡说八道'，其实问题出在提示词上——就像业务方丢给你一句'我要一个五彩斑斓的黑'，你也无法准确执行。"
- **顿号承担三项并列**（14.7/千字）：
  > "需求分析、设计、编码、测试、部署每个环节都需要专业人员"
  > "比如拆分用户故事、工作量估算、会议总结等"
- **三点式单句成段**：
  > "第一层是'助手'，核心是提高效率；"
  > "一是定义意图，明确业务目标和期望结果；"

## 4. 语用与现场感

**A 档（课堂/内训）**
- **第二人称指令句多**：不用"建议大家"，直接"你把它写成一个陈述句""你可以用这个……""记住啊"。
- **反问代替断言**："那我问一句……行不行？"
- **现场点名与应答**："我看到有位同学到了""然后还有一位新朋友是吧？""看到了某位同学"。
- **寒暄式开场**：从天气/近况切入（"这位同学，这穿的也挺多的，你们那也冷。对，这两天降温。"）。
- **允许过渡口水**："好，那该铺垫的铺垫完了""我们看接下来这个……"
- **自嘲**："我觉得我现在我自己就像100年前200年前的这个奴隶主一样的，谁是我的牛马？"
- **收尾三件套**："OK，我就讲这么多好吧" → "大家也去吃饭，好吧？" → "咱们江湖再见 / 拜拜拜拜"

**B 档（会议演讲成稿）**
- **开场实物道具 + 致谢**："大家上午好！感谢漂亮的主持人。刚刚我拿的这本书是《Clean Agile》的全新翻译版……"
- **对同行温柔调侃**："当然下午也会有老师会分享编程相关内容，看看他们能不能'救活'它。"
- **设问后立刻自答并预告**："大家可能会担心'这需要编程吗？'，答案是不需要，接下来我会告诉大家。"
- **引述他人后反转**：
  > "曾有人说'AI时代值得把所有应用都重新用AI做一遍'，**但我并不认同**。"
  > "很多人说'人不会被AI替代，因为人有同理心'，**但我不完全认同**。"
- **提炼成一句主张**："我总结的基本提示词技巧就是：心平气和地把话说清楚。"
- **当场案例自指**："第三个案例是我的一个外资制造业客户。"
- **结尾金句**："AI不会取代敏捷，更不会取代敏捷教练，但懂AI的敏捷教练一定会取代不懂AI、不愿动手的教练。"

## 5. 修辞手法

### 5.1 类比是主力（两档通用）

把抽象概念落到**身体经验或日常物件**上：
- 算力 → "你的耐力、你的灵敏度、你的脑子的清醒度"
- 知识库 → "就像我们电脑上有一个外接硬盘，你内存就这么大"
- 生成式 AI → "生成式AI就是一个续写句子……小学就叫总结中心思想"
- 需求描述 → "就像业务方丢给你一句'我要一个五彩斑斓的黑'，你也无法准确执行"
- 智能体管理 → "第一点是'记忆与同步'，相当于Agent的'每日站会'"

### 5.2 拟人化
"你就把它当成一个人来对待，你就知道怎么和他共同的相处。"
"AI就像一面镜子，能折射出你是否能清晰表达需求。"

### 5.3 反差与落差数字（A 档）
用时间跨度制造冲击："半年过去了""再开发它要多久呢？少说三个月""这一年就过去了"。

### 5.4 概念翻译成既有体系（B 档）
把陌生的东西挂到他熟悉的框架上——Agent 的记忆 → 每日站会；Agent 的完成检查 → DoD；Agent 的反馈循环 → TDD。**这是他讲新概念的主要手法。**

## 6. 语篇结构

### 6.1 概念讲解套路（A 档教学，最完整的一套）
1. **抛现象**：先给一个大家都见过的场景
2. **提问**："大家有没有发现……？"
3. **类比**：落到身体/日常经验
4. **拆解**：三件套（如"知识 / 算法 / 算力"）
5. **回扣听众**："所以我们认为使用AI最终的受益者就是……你看广阔灵活，对吧？"

### 6.2 案例叙事骨架（两档通用）
**时间地点人物锚点 → 冲突 → 转折（对方怎么做）→ 结论**

> "有一年我在南京讲过一次课，那次是一家银行总行组织的……某个分支行的行长讲他们办ETC……结果他们买了几天，一个客户也没捞到。为什么？就是他们的IT系统没有提了需求……他们就自己做了一个小小的网站，小小的网页。"

B 档版本则是**编号案例 + 共性收束**：
> "第一个案例是……第二个案例是……第三个案例是……这三个案例的核心共性的是，它们解决的都是非规则化、难以用传统规则（if-then）描述的问题。"

### 6.3 B 档的章节骨架
`一、敏捷的危机与天时` → `二、AI 适合解决的问题` → `三、多智能体和AI员工` → `四、管理"AI hybrid 团队"` → `五、未来展望`
**编号章节 + 明确的听众收益预告**（"今天就跟大家分享几个最新案例"）。

### 6.4 现场结构词
"第一个/第二个/第三个"推进；"我们看接下来这个……"切换；"好，这个问题先放这儿"挂起。

### 示例 A · A 档（课堂口语稿）

**改写前：**
> 综上所述，AI 赋能研发流程将极大提升团队效率。我们通过引入 AI Agent，打造智能化的研发闭环，从而帮助组织实现敏捷的数字化转型。这不仅是一次效率飞跃，更是研发范式的根本变革。

**改写后：**
> 所以你把AI放进研发流程里，效率确实不一样。我们现在是拿AI Agent来干活，不是拿聊天机器人。这套东西跑顺了，团队迭代的速度就快下来了。
>
> 好，这块儿就讲到这儿。

改了什么：拆掉三段式拔高；删掉四个 AI 高频词；去掉"综上所述/不仅…更是"；换成"所以/我们现在是/好，这块儿就讲到这儿"的 A 档推进词；保留"确实"这一原有限定。**没有添加任何原文没有的效率数据。**

### 示例 B · B 档（演讲实录发布稿）

**改写前：**
> 传统经验萃取存在三大原罪，导致经验无法有效传承，人才断层风险日益凸显。组织亟需探索一条全新的知识沉淀路径。

**改写后：**
> 传统经验萃取有三大原罪。经验传不下去，人一走，能力就断了。
>
> 后面我讲一条能走通的路。

改了什么：去掉"日益凸显""亟需探索"这类公文腔；把抽象后果落成"人一走，能力就断了"；用"后面我讲一条能走通的路"替代"组织亟需探索"。**保留了"三大原罪"这个原有结构，没有改动数字，没有引入 A 档的"对吧"。**

### 示例 C · B 档的论证句

**改写前：**
> 很多人认为AI不会取代人类，因为人类具有同理心。然而这一观点并不完全成立。

**改写后：**
> 很多人说"人不会被AI替代，因为人有同理心"，但我不完全认同。

改了什么：B 档主张**先复述对方原话再反转**，而不是先否定再解释；引号内保留对方原话，保持归因边界。**原文没有的论据一律不补**——哪怕角色卡里有现成的例子。

### 示例 D · 事实边界（不可越界）

**改写前：**
> 这个工具的成本比传统方式低。

**改写后（正确）：**
> 这个工具的成本比传统方式低。

**错误改法（不可接受）：**
> 这个工具的成本比传统方式低，找机构老师精批一篇作文要 100-300 元、周期 3-7 天，而这个工具一分钟就能完成批改。

角色卡里有 100-300 元、3-7 天、一分钟这些**真实数据**，但它们属于另一篇文章。**角色卡提供表达方式，不提供可以搬进目标文本的内容。**
